DUO PWA

1. Upload alle filer fra denne mappe til et gratis statisk HTTPS-webhotel (f.eks. GitHub Pages eller Cloudflare Pages).
2. Aabn HTTPS-adressen i Chrome paa Android.
3. Tryk menuen med tre prikker og vael Installer app eller Foej til startskaerm.
4. Appen aabner derefter fra sit eget ikon.

VIGTIGT: En lokal HTML-fil eller zip-fil kan ikke installeres som fuld PWA.
OpenStreetMap/Overpass-stedsoegningen fra version 1.6 er endnu ikke repareret og kan fejle. Fotos og stedsoegning kraever internet. Favoritter gemmes kun lokalt paa den enkelte enhed. Hosting og gratis API-tjenester har brugsbegraensninger.
